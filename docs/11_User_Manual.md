# 11. User & Administrator Manual

## 1. Visitor / User Guide

### 1.1 Navigating Categories
- Browse the top navigation menu or category cards on the homepage.
- Click any category (e.g., **সরকারি প্রকল্প**, **অনলাইন সেবা**, **চাকরি**) to view filtered articles.

### 1.2 Using the Citizen Online Tools
- Navigate to **দরকারী টুলস** (`/tools`) from the top header.
- **Image Compressor**:
  1. Click "ছবি আপলোড করুন" (Upload Image).
  2. Choose the target maximum size (e.g., 20KB, 50KB, 100KB).
  3. Real-time preview displays original size vs compressed size.
  4. Click "ডাউনলোড করুন" (Download) to save the resized image.
- **Card & Signature Cropper**:
  1. Select preset: *Aadhaar Card*, *Voter ID*, *PAN Card*, or *Signature (140x60)*.
  2. Position and zoom the image within the bounding frame.
  3. Click "ক্রপ এবং ডাউনলোড" (Crop & Download).

### 1.3 Bookmarking & Commenting
- Click the bookmark icon on any article to save it to your profile reading list.
- Post comments at the bottom of any article.

---

## 2. Administrator Guide

### 2.1 Accessing the Admin Dashboard
- Navigate to `/admin/login` or log in with an administrator account.
- Redirects to `/admin/dashboard`.

### 2.2 Publishing an Article
1. In the sidebar, select **Posts** -> **Add New Post**.
2. Enter Bengali Title, select Category, upload Featured Image.
3. Write article content using the rich Markdown editor.
4. Provide SEO Meta Title and Description.
5. Choose status: `Published` or `Draft` and click **Save Article**.

### 2.3 Managing Categories & Comments
- Under **Categories**, create new topics with custom Bengali display labels and icons.
- Under **Comments**, review pending reader feedback and toggle approval or deletion.
- Under **Subscribers / Messages**, review contact inquiries and newsletter subscribers.
